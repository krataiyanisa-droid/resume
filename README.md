## GitHub Pages
1. สร้าง Repository ชื่อ `YOUR_USERNAME.github.io`
2. Upload ไฟล์ทั้งหมดในโฟลเดอร์นี้

6. Folder = `/ (root)`
7. กด **Save**
8. เว็บไซต์จะเป็น `https://YOUR_USERNAME.github.io/`
